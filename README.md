# zmk-config-AroundFortyRB (zmk-v0.4)

Around Forty RB の ZMK v0.4（Zephyr 4.1）対応版ファームウェアです。

本ブランチは、次期メジャーバージョンである **ZMK v0.4 (Zephyr 4.1)** に先行対応するための開発ブランチです。

---

## 主な実装内容・特徴

### 🟢 ZMK v0.4 (Zephyr 4.1) への移行
- **最新 Zephyr 4.1 対応**: ZMK main（Zephyr 4.1 系統）を pin し、新規格に適合
- **新ボード定義形式への対応**: ボード指定を `xiao_ble//zmk`、インターコネクト ID を `seeed_xiao` に更新
- **Devicetree での NFC ピン GPIO 化**: Zephyr 4.1 での Kconfig 廃止に伴い、P0.09 / P0.10 の GPIO 再利用指定を DTS（`&uicr`）へ移行
- **外部モジュールの Zephyr 4.1 追従**:
  - `badjeff/zmk-pmw3610-driver`: Zephyr 4.1 上流との衝突回避のため `pixart,pmw3610-alt` / `CONFIG_PMW3610_ALT_*` に追従
  - `caksoylar/zmk-rgbled-widget`: Zephyr 4.1 対応版へ更新

### 🟢 トラックボールおよび BLE 通信の最適化
- **トラックボール応答性・復帰速度の改善**: 報告間隔（15ms）の同期および復帰遅延チューニング
- **BLE スタックメモリ・バッファ最適化**: `CONFIG_BT_HCI_TX_STACK_SIZE_WITH_PROMPT=y` の適用など左右のスタック設定を最適化

### トラックボールの通常移動・精密移動
- **通常時**: センサー感度800 CPIで、従来の400 CPI設定の約2倍の移動量
- **レイヤー7（`layer_10`）有効時**: 移動量を半分にして、従来と同じ400 CPI相当で精密操作。既存のレイヤー7切り替えキーで利用可能
- **レイヤー8（`V_Scroll`）有効時**: 従来のスクロール速度・方向を維持。レイヤー7も有効な場合はスクロールを優先

画面上の移動距離は、接続先OSのポインター速度や加速設定にも影響されます。

### Mac / Windows モード切り替え

ベース層の設定レイヤーキー（右下段の右から2番目）を押しながら、左上の **Q** を押すと、Mac / Windows モードが切り替わります。キーを離しても選択したモードを維持し、同じ操作でもう一方に戻せます。電源投入・再起動時はMacモードです。Bluetooth接続先の選択はモード切り替えとは独立しています。

**右側のRGB LEDで現在のモードを確認できます：緑＝Mac、青＝Windows。** 数字・記号・精密移動・スクロールなどの一時レイヤーでも、モードの色を保ちます。起動時やBluetooth接続先の変更時、電池残量の通知時は一時的に従来のステータス表示になり、その後モードの色に戻ります。スリープ時は消灯します。使用中の常時点灯により、以前の消灯設定より消費電力は増えます。

Windows側は **英語配列（US）** とMicrosoft IMEを想定しています。文字・数字・記号・マウスボタンの位置はMacモードと共通です。

| 操作・位置 | Mac | Windows |
| --- | --- | --- |
| 左下段のCommand位置 / 右Command位置 | Command | Ctrl |
| 左下段のControl位置 | Control | Windowsキー |
| 中央のIME切り替えキー | Ctrl + Space | Alt + Grave |
| コピー・貼り付け・切り取り・検索・再読み込み | Command系 | Ctrl系 |
| 範囲キャプチャ / キャプチャUI | Macの画面キャプチャ | Win + Shift + S |
| 全画面キャプチャ | Command + Shift + 3 | Win + PrintScreen |
| ナビゲーション層の戻る / 進む | Command + ← / → | Alt + ← / → |
| 精密移動 | レイヤー7 | 同じキー位置でレイヤー16 |
| スクロール | レイヤー8 | 同じキー位置でレイヤー17 |

Mac固有のウィンドウ操作は、Windowsのタスクビュー・仮想デスクトップ移動・最大化/最小化などに置き換えています。F11による全画面表示やブラウザー操作は、対応するアプリで動作します。既存のアプリ固有ショートカット `Ctrl + Shift + GUI + A/Z` はそのまま残しています（WindowsではGUIはWindowsキー）。必要に応じて利用するアプリの設定に合わせてください。

既存のMac用レイヤー0〜8を維持し、Windows用レイヤー9〜17を追加しています。Windowsモード中の設定レイヤー内のベース層復帰キーは、Windowsのベース層に戻ります。

### 🟢 ZMK Studio 対応
- `studio-rpc-usb-uart` スニペットを有効化し、USB 接続時のリアルタイムキーマップ編集に対応

### 🟢 全角半角の切り替えマクロ
- `ime_tog` マクロにより、1 つのキーで日本語入力の全角/半角トグル切り替えが可能
